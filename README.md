# Ашық сабақ · Физика

Физика пәнінен ашық сабақ сайты: бейнесабақ (15 бөлім), сабақ барысы, негізгі ұғымдар, интерактивті зертхана (Гук заңы, психрометр), тест, проблемалық сұрақ және рефлексия.

Дайындаған оқушы: **Дамир Ж.**
